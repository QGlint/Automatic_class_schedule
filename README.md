# Automatic Class Schedule（自动排课系统）

一款面向初中学校的 Windows 本地排课软件，基于约束求解引擎实现全自动智能排课，支持人工微调与冲突检测，帮助教务人员快速生成高质量课表。

## 核心功能

- **智能自动排课** — 基于 Google OR-Tools CP-SAT 约束求解器，以班级为整体单位进行全局建模，一次性生成满足所有硬约束（教师/班级时间冲突、固定课程、体育连班≤2等）并最大化软偏好得分的课表
- **拖拽手动调整** — 支持在课表界面直接拖拽交换课程位置，即时生效；冲突仅提示，不自动触发重排
- **局部调整优化** — 一键触发五轮渐进松弛策略的局部求解，智能修复冲突区域，保留已锁定课程
- **实时冲突检测** — 硬冲突（红色）与软冲突（黄色）分级显示，提供详细冲突原因说明
- **多维度课表查看** — 年级总表、班级课表、教师课表三种视图自由切换
- **Excel 导入/导出** — 支持导入排课数据，导出年级课表、班级课表、教师课表等多种格式
- **教师智能生成** — 支持"所带班数"与"年级老师数"双模式配置，可按年级自定义，方案模板可保存/切换
- **课程配置模板** — 内置初中标准课程模板，支持自定义配置与方案持久化
- **项目管理** — 支持新建/打开/最近项目，固定课蓝色标记保留

## 技术栈

| 层级 | 技术 |
|------|------|
| UI 框架 | WinUI（Build 2026）/ Windows App SDK 2.3 |
| 运行时 | .NET 10 / C# |
| 求解引擎 | Google OR-Tools CP-SAT 9.14 |
| Excel 处理 | ClosedXML |
| 数据控件 | CommunityToolkit DataGrid |
| 架构模式 | MVVM |

## 运行环境

- Windows 10（1809+）/ Windows 11
- 支持 x64 / x86 / ARM64 架构
- 非打包（Unpackaged）桌面应用，无需安装即可运行

## 适用场景

- 初中学校（七、八、九年级）学期课表编排
- 教务人员快速生成与调整全校课表
- 多班级、多教师、多约束条件下的自动化排课

## 构建与运行

```bash
# 构建
make build

# 运行（含编译）
make run-full
```
